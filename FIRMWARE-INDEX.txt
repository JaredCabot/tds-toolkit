TDS500/600/700 firmware images
==========================================================================

One file per distinct image. Tektronix shipped one image for a
whole family, so FITS lists every model an image is for and the
filename names none of them.

FV is what the instrument reports to *IDN? once the image is
loaded, from the $VersionString: FV:v... tag inside it.

The eight hex digits in a filename are the start of the image's
SHA-256. They are what makes a name unique: two different images
can carry the same FV.
