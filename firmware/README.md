# Firmware images

`TDS-firmware-images.zip` is the TDS500/600/700 firmware library the
**Firmware tab** flashes from — one file per distinct image (32 of them),
each with its erased `0xFF` flash tail trimmed off, plus a
`FIRMWARE-INDEX.txt` inside the zip that lists which models each image fits
(the FITS column) and the SHA-256 of both the trimmed and the full image.

The app reads firmware straight from the zip, so to use it just point the
Firmware tab's folder at this directory. Padding a trimmed image back up to
its full size with `0xFF` reproduces the image exactly as it was dumped —
nothing is lost, because the flash is erased to `0xFF` before a write.

Tektronix permits free distribution of the firmware and manuals for these
obsolete instruments.

The archive is regenerated by `tools/build_firmware_zip.py` from the
maintainer's local image library; see `CLAUDE.md`.
